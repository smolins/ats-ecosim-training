# EcoSIM capability questions

Use `reference/CURRENT.md` to find the ATS and EcoSIM source revisions shipped
with this image. The relevant code is:

- `reference/ats/<revision>/src/pks/ecosim/` for the ATS–EcoSIM coupling.
- `reference/ecosim/<revision>/` for EcoSIM's own implementation.
- `examples/ecosim/inputs/` for the settings exercised by the lessons.

When answering a capability question, inspect the implementation and relevant
input examples. Cite specific relative file paths and functions or subroutines.
Distinguish capabilities present in the code from features enabled by the
current XML input. Say when the source does not establish an answer. Source
copies are for reference; editing them does not change the installed executable.
Only edit files or run simulations when the participant asks you to.
